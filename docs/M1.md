# M1 — Local station catalogue and observation logbook

M1 turns the M0 foundation into a useful local-first backend without requiring an SDR, API key or external provider.

## Delivered

- persistent station catalogue: name, aliases, languages and notes
- persistent observation log: station, UTC timestamp, frequency in Hz, mode, signal report, message/transcription and notes
- `GET /api/stations`
- `POST /api/stations`
- `GET /api/observations`
- `POST /api/observations`
- atomic local persistence at `/data/number-station-tools.json`
- `NUMBER_STATION_TOOLS_DATA` override for host tests/runs
- dependency-free Go implementation; existing CGO-free multi-architecture container build is preserved
- persistence regression test

M1 intentionally uses JSON persistence rather than introducing a third-party SQLite driver before the schema matures. SQLite remains a later migration target.

## Qualification

Run:

```sh
go test ./...
go vet ./...
go build ./cmd/number-station-tools
```

For a host smoke test, set `NUMBER_STATION_TOOLS_DATA` to a writable path before starting the service.
