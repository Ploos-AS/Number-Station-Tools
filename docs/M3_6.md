# M3.6 — Mini spectrogram preview

M3.6 adds a compact time-frequency preview for managed PCM WAV recordings.

## Scope

- 24 time bins across the recording
- 32 frequency bins from above DC to Nyquist
- Hann-windowed analysis
- mono analysis derived from all channels
- 8-bit and 16-bit PCM WAV support through the existing managed ingest path
- normalized `uint8` intensity matrix persisted in recording metadata
- `spectrogram_time_bins`, `spectrogram_frequency_bins`, and `spectrogram_max_hz` describe the matrix
- recording archive renders the preview from metadata without downloading the audio file
- managed spectrogram fields are preserved by ordinary metadata edits

FLAC upload and metadata extraction remain supported, but compressed FLAC is not decoded for spectrogram generation in M3.6.

No ffmpeg, ffprobe, FFT library, SDR hardware, API key, or external service is required.

## Qualification

Regression coverage uses a generated 1 kHz PCM WAV and verifies that the expected frequency region remains dominant across the full set of time bins. Standard CI also runs formatting, all Go tests, vet, binary build, and container build.
