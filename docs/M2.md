# M2 — Schedules and frequencies

M2 adds local UTC transmission schedules and frequency plans linked to stations.

## Scope

- schedule records linked to an existing station
- frequency in Hz
- UTC start/end time (`HH:MM`)
- day-of-week mask using ISO weekday numbers (1=Mon ... 7=Sun)
- optional mode and notes
- `GET /api/schedules`
- `POST /api/schedules`
- schedule persistence in the existing local data file
- validation for station existence, positive frequency, valid UTC times and weekdays
