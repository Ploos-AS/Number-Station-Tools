# M0 — Foundation

Status: implemented

## Goal

Create a minimal, runnable baseline for Number Station Tools without coupling
the application to SDR hardware, external station databases or online-only
providers.

## Acceptance criteria

- [x] Go application builds as a single binary.
- [x] Web UI is embedded in the binary.
- [x] HTTP health endpoint exists at `/healthz`.
- [x] OCI image uses a multi-stage build.
- [x] Runtime container is non-root.
- [x] `/data` exists as the persistence contract.
- [x] Compose example is present.
- [x] No SDR hardware, API keys or external providers are required.
- [x] MIT license is present.

## Explicitly deferred

- SQLite schema
- station database
- schedule ingestion
- recording management
- spectrogram generation
- transcription/segmentation
- SDR or KiwiSDR integrations
- SigMF support
- authentication

Those belong in later milestones and should be added behind stable internal
interfaces rather than coupled to the M0 HTTP bootstrap.
