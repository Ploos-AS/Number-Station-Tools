# M3.7 — Signal fingerprints and similarity

M3.7 adds a compact, local signal fingerprint to managed PCM WAV recordings and a deterministic similarity search over the recording archive.

## Fingerprint

- 32 normalized `uint8` bins.
- Derived from the mini-spectrogram when available, otherwise from the frequency preview.
- Generated during managed WAV ingest.
- Persisted as recording metadata.
- Treated as server-derived immutable metadata during ordinary recording edits.
- FLAC recordings remain supported; without decoded frequency/spectrogram data they currently receive no fingerprint.

## Similarity

`GET /api/recordings/{id}/similar?limit=5`

- Compares fingerprints using cosine similarity.
- Returns a percentage score from 0 to 100.
- Sorts highest similarity first.
- Excludes the source recording itself.
- Limits results to at most 20.
- Requires no AI model, API key or external service.

The recording archive exposes a **Find similar** action for each recording.

## Qualification

Regression coverage verifies that nearly identical synthetic spectral profiles score higher than separated profiles and that store-level similarity results are sorted descending.
