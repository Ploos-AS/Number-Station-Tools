# M4.4 — Visual annotation markers

M4.4 projects the persistent recording annotations introduced in M4.3 directly onto the local signal-analysis previews.

## Scope

For recordings with a known duration and waveform and/or mini-spectrogram previews:

- point annotations render as narrow vertical markers at their saved timestamp;
- interval annotations render as translucent horizontal regions from `start_ms` to `end_ms`;
- the same saved annotation is rendered on both waveform and spectrogram when both previews exist;
- hover and keyboard focus expose the annotation label through an inline label and native tooltip;
- marker accessibility text includes label, timestamp/interval and optional note;
- clicking a marker seeks managed recording playback to the annotation start time.

The annotation list and CRUD API from M4.3 remain authoritative. M4.4 introduces no new persistence format and no data migration.

## Duration semantics

Marker position is calculated from the recording's persisted `duration_ms`. Recordings without a positive known duration still retain and expose their annotations in the annotation list, but no timeline marker is rendered because a stable horizontal position cannot be derived.

## Local-first behavior

Rendering happens entirely in the embedded browser UI using annotation metadata already stored in `recordings.json`. No audio, annotation, station or observation data is sent to an external service.

## Interaction with playback and loops

Visual annotation markers are layered above the waveform/spectrogram preview and the temporary M4.2 A-B loop region. The playback cursor remains visible. Clicking an annotation marker only changes browser playback position; it does not alter the saved annotation, audio file or A-B loop state.
