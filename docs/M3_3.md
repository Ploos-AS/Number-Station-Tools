# M3.3 — Automatic audio metadata extraction

M3.3 enriches managed WAV and FLAC uploads without external multimedia tools.

## Managed ingest metadata

After signature validation and before the upload is finalized, the server extracts:

- duration in milliseconds
- sample rate in Hz
- channel count

The extracted values are persisted in the existing recording metadata entry together with size, SHA-256, original filename and observation linkage.

## WAV

The parser reads RIFF/WAVE chunks, finds `fmt ` and `data`, and derives sample rate, channel count and duration from the declared byte rate and data length. Unknown chunks are skipped according to RIFF chunk alignment rules.

## FLAC

The parser reads the mandatory STREAMINFO metadata block and extracts sample rate, channel count and total sample count. Duration is derived from total samples and sample rate.

## Failure policy

A managed file with a valid outer WAV/FLAC signature but unusable or incomplete structural metadata is rejected before it is finalized. No recording metadata entry is created for a failed ingest.

## Scope

M3.3 does not decode audio samples, transcode files, generate waveforms, or depend on ffmpeg/ffprobe. Existing external metadata-only recording entries remain unchanged.
