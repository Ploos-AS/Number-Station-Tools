# M2.1 — Schedule UI and UTC now/next

M2.1 makes the M2 schedule model usable from the web application and adds a
server-side UTC view of current and upcoming transmissions.

## Scope

- create stations from the web UI
- create schedules from the web UI
- list stored schedules with station name, frequency, UTC time, weekdays and mode
- `GET /api/now-next`
- server-side UTC schedule evaluation
- active transmission detection
- next five upcoming transmissions
- schedules that cross midnight are handled correctly
- dashboard refreshes automatically once per minute

## UTC rules

Schedules remain expressed as ISO weekdays (`1` = Monday, `7` = Sunday) and
`HH:MM` UTC times. If `end_utc` is not later than `start_utc`, the transmission
is treated as crossing midnight into the next UTC day.

The now/next engine evaluates the previous UTC day as well as future days so an
overnight transmission remains active after midnight.
