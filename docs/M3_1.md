# M3.1 — Recording API and web UI

M3.1 exposes the M3 recording-metadata foundation through the main HTTP server and web application.

## Scope

- open `/data/recordings.json` at application startup
- optional override with `NUMBER_STATION_TOOLS_RECORDINGS`
- same-origin recording metadata API
- create, list, update and delete recording metadata
- per-observation recording lookup
- web form for WAV/FLAC metadata
- recording archive with search/filter
- `Add recording` pivot from each observation
- observation cards show recording counts
- deleting an observation is blocked while recording metadata references it
- deleting recording metadata never deletes or modifies the referenced audio file

## API

- `GET /api/recordings`
- `POST /api/recordings`
- `PUT /api/recordings/{id}`
- `DELETE /api/recordings/{id}`
- `GET /api/observations/{id}/recordings`

## Metadata

Each recording entry can contain:

- observation ID
- local path/filename
- `wav` or `flac`
- size in bytes
- duration in milliseconds
- sample rate in Hz
- channel count
- optional SHA-256
- notes

M3.1 remains metadata-only. The HTTP server does not upload, stream, transcode or delete audio files.
