# M4.5 — annotation editing and direct timeline creation

M4.5 extends the local recording workbench without changing the annotation storage schema or API shape introduced in M4.3.

## Editing

Existing saved annotations now have an Edit action. Editing loads the annotation into the existing form, preserves its stable annotation ID, and submits through the existing `PUT /api/recordings/{id}/annotations/{annotationID}` endpoint. Cancel returns the form to create mode.

## Direct timeline bookmarks

When a recording has known duration, right-clicking a waveform or mini-spectrogram position immediately creates a point annotation labelled `Bookmark` at that exact timeline position. This uses the existing annotation POST endpoint and persists to `recordings.json`.

For keyboard use, focus a seekable waveform/spectrogram preview and press `B` to create the same Bookmark at the current playback position.

Direct creation is deliberately limited to point bookmarks. Operators can immediately use Edit to rename the bookmark, add notes, or convert it into an interval by setting an end time.

## Local-first boundary

M4.5 performs no external requests beyond the appliance's own API, adds no new dependency, and does not alter audio data. Existing A-B loops remain browser-session state; saved annotations remain persistent local metadata.

## Qualification

The standard CI gate must pass formatting, Go tests (including embedded M4.5 frontend regression coverage), `go vet`, Go build, and OCI container build before merge.
